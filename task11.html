Task 11. Mini Project: Accordion Menu

What is jQuery?

jQuery is a JavaScript library that makes it easier to work with the DOM, events and animations.

What are selectors?

Selectors help us to find HTML elements by ID, class or tag name, for example $("#id"), $(".class"), $("p").

What are effects?

Effects are methods like hide, show, fade and slide that change how elements appear on the page.

What is animate()?

The animate() method changes CSS properties smoothly, for example size, position and opacity.
