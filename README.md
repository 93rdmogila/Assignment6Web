## Description

This project contains all tasks of Assignment #6 about jQuery.
Every task is on a separate HTML page. The pages are connected with a navigation bar.
The project uses only HTML, CSS, JavaScript and jQuery (loaded from the CDN).

| Page | Content |
|------|---------|
| task0.html | Setup: jQuery CDN, `$(document).ready()`, message in the console |
| task1.html | Selectors by ID, class, tag; `.text()`, `.html()`, `.css()` |
| task2.html | `.hide()`, `.show()`, `.toggle()` |
| task3.html | `.fadeIn()`, `.fadeOut()`, `.fadeToggle()` |
| task4.html | `.slideUp()`, `.slideDown()`, `.slideToggle()` |
| task5.html | `.append()`, `.prepend()`, `.remove()` |
| task6.html | Changing `src` and `href` with `.attr()` |
| task7.html | Form with Name and Email, `.val()` and `.text()` |
| task8.html | Basic animation with `.animate()` |
| task9.html | Sequential animations |
| task10.html | Combined animation (opacity, size, movement) |
| task11.html | Mini project: Accordion Menu |

## Project structure

```
index.html        - home page
task0.html ... task11.html
style.css         - one common CSS file
images/           - two simple images for tasks 3 and 6
README.md
```

## How to run

1. Download or clone the repository.
2. Open `index.html` in a browser (double click).
3. Use the navigation bar to open the tasks.

An internet connection is needed because jQuery is loaded from the CDN.

## GitHub Pages

1. Push the files to a GitHub repository (`index.html` must be in the root folder).
2. Open Settings -> Pages.
3. In "Branch" choose `main` and the `/ (root)` folder, then press Save.
4. After a minute the site will be available at `https://<username>.github.io/<repository>/`.
